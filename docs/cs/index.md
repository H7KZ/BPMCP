## Co to je?

**InSIS MCP** je vzdálený server [Model Context Protocol](https://modelcontextprotocol.io), který zpřístupňuje studijní
data **InSIS** z VŠE — předměty, rozvrhy a studijní plány — AI asistentům jako Claude nebo Cursor.

Nasměrujte klienta na endpoint a ptejte se přirozeným jazykem:

> _„Které semináře pro 4IZ268 se hodí do úterního dopoledne?"_

Adresa pro připojení je:

```
https://bpmcp.vse.cz
```

Pokračujte na [Začínáme](/cs/guide/getting-started) a připojte prvního klienta.
